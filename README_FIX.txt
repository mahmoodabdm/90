
# الباحث العلمي AI - النسخة الكاملة المصححة
Package Name: com.albahithai.search.pro2026

طريقة البناء:

1- انسخ فولدر android هذا والصقه فوق فولدر android القديم بمشروعك
2- افتح CMD داخل فولدر المشروع الرئيسي (اللي بيه pubspec.yaml)
3- اذا عندك فلاتر: flutter build appbundle --release
4- اذا ما عندك فلاتر ونصبت اندرويد ستوديو: gradlew.bat bundleRelease داخل فولدر android

الـ AAB الجديد راح تلكاه في:
android/app/build/outputs/bundle/release/app-release.aab

هذا الملف هو اللي ترفعه لكوكل بلي
